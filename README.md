# Advanced Golang Programming Workbook

Practice advanced Go concepts like concurrency, error handling, and more by building small weekend projects.

## Projects

Each folder in this repo contains a set of requirements for small CLI utils. By building each of the utilities, you will practice some Go concepts:

- **WordCounter** – concurrency
- **PizzaCLI** – efficient memory usage
- **Gophetcher** - error handling, OOP, code quality
- **Stargo** - reflection and metaprogramming
- **Gorge** - generics

Each folder contains my version of the implementation. You can use it as a reference if you want

## Project description structure

Each project has the following description structure:

### Overview

A brief description of the CLI tool you're going to build

### Requirements

Detailed requirements of what needs to be done within the project

### CLI Interface Specs

How the CLI interface should look

### Success Criteria

Concrete definitions of done

### Constraints

What libs, frameworks, and tools to use or not to use. Of course, you can make those constraints stricter or softer according to your needs and desires
